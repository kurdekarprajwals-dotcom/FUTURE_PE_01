# FUTURE_PE_01

## AI Website Copy Generator for Local Businesses

**Internship:** Future Interns — Prompt Engineering Internship
**Task:** Task 1
**Business:** Green Leaf Cafe
**Location:** Shivamogga, Karnataka, India

## 1. Project Overview

This project demonstrates how prompt engineering can be used to generate clear, engaging, and business-specific website copy for a local cafe.

The goal is to create website content that communicates the business's offerings, explains its value to customers, and encourages visitors to explore its products and services.

## 2. Business Chosen

Green Leaf Cafe is a fictional local cafe based in Shivamogga, Karnataka.

The example website content focuses on:

* Coffee and tea
* Snacks and sandwiches
* Desserts
* A welcoming cafe experience

The business is fictional and is used for educational purposes.

## 3. Tools Used

* **ChatGPT:** Used to develop prompts and generate website copy.
* **GitHub:** Used to store and share the project files.

## 4. Prompt Logic

The prompt framework uses structured instructions to generate relevant website content.

The prompts consider:

* Business name and type
* Target audience
* Products and services
* Brand tone and language
* Customer benefits
* Calls to action (CTAs)

These details help produce content that is more relevant to the selected business than generic website text.

## 5. Project Deliverables

The repository contains the following files:

* `README.md` — Project overview, business information, tools, and prompt logic.
* `prompts.md` — Structured prompts used to generate website content.
* `homepage-copy.md` — Homepage headline, subheadline, and introduction.
* `prompt-analysis.md` — Analysis of the prompt design and expected output.
* `services-copy.md` — Products and services website content.
* `cta-copy.md` — Call-to-action sections designed to encourage customer engagement.

## 6. Key Features

* Business-specific website copy
* Benefit-focused messaging
* Clear calls to action
* Reusable prompt structure
* Adaptable tone and language
* Content organised into separate Markdown files

## 7. Responsible Use

The content is a demonstration created for an educational prompt engineering project.

Green Leaf Cafe is fictional. Actual business information, contact details, opening hours, menu items, and availability must be verified before publishing content for a real business.

## 8. Conclusion

This project demonstrates how structured prompts can help generate organised website copy for local businesses. The same framework can be adapted for other business types by changing the business details, target audience, services, and preferred tone.
