# Prompt Analysis — Green Leaf Cafe

## 1. Project Overview

This project explores how prompt engineering can help generate website copy for a fictional local business.

Business name: Green Leaf Cafe
Location: Shivamogga, Karnataka
Target audience:
- College students
- Working professionals
- Families

Business categories:
- Coffee and tea
- Snacks and sandwiches
- Desserts

## 2. Objective

The objective is to generate clear, friendly, and professional website content using an AI tool.

The content should introduce the cafe, describe its products, explain why customers might visit, and encourage visitors to explore the menu.

## 3. Initial Prompt Analysis

The initial prompt specifies the business name, location, target audience, products, and required website sections.

### Strengths
- Clearly identifies the fictional business.
- Defines the target customers.
- Lists the required website sections.
- Requests simple and professional English.
- Instructs the AI to avoid unsupported claims.

### Limitations
- Does not specify the exact number of headline options.
- Provides limited guidance on organizing product descriptions.
- Does not explicitly require placeholders for missing contact information.

## 4. Improved Prompt Analysis

The improved prompt provides more detailed instructions for generating the website content.

### Improvements
- Requests three alternative homepage headlines.
- Organizes products and services into categories.
- Specifies five call-to-action button labels.
- Requests placeholders for contact information.
- Requires short paragraphs and natural English.
- Asks the AI to explain the improvements.

## 5. Comparison

| Feature | Initial Prompt | Improved Prompt |
|---|---|---|
| Homepage headlines | General headline | Three alternatives |
| Product descriptions | General descriptions | Organized categories |
| Call-to-action buttons | Requested | Five labels requested |
| Contact details | Contact section | Explicit placeholders |
| Writing style | Simple and professional | Natural, friendly, and concise |
| Output instructions | General | More specific |

## 6. How Prompt Engineering Helped

The improved prompt breaks the task into smaller, clearly defined requirements.

It gives the AI more information about the desired structure, writing style, and output.

This can make the generated content more consistent and easier to review.

However, the output still needs human checking to ensure that it is accurate, useful, and appropriate for the intended audience.

## 7. Limitations

- Green Leaf Cafe is a fictional business.
- The generated content does not confirm actual products, prices, or opening hours.
- Contact information must be provided and verified separately.
- AI-generated content may require editing before publication.

## 8. Conclusion

This exercise demonstrates how specific instructions can improve the structure and usefulness of AI-generated website copy.

The initial prompt establishes the basic requirements, while the improved prompt provides clearer output expectations.

Prompt engineering helps guide AI generation, but human review remains important.
